# Supermarket Sales Analysis with Python

## Project Overview
This project explores supermarket sales data to assess data quality, analyse revenue patterns, and identify customer and order-level trends using Python.

## Tools and Technologies
- Python
- Jupyter Notebook
- pandas
- Matplotlib
- Excel

## Project Workflow
1. Loaded the Excel dataset into pandas.
2. Inspected and corrected data types.
3. Checked missing values and duplicate records.
4. Validated order dates and sales-total calculations.
5. Analysed monthly revenue and order volumes.
6. Identified high-revenue customers.
7. Analysed revenue by order quantity.
8. Developed business findings and recommendations.

## Key Findings
- Total recorded revenue: $10,855.15
- Total orders: 70
- Total items sold: 168
- Average order value: $155.07
- Average order quantity: 2.4 items
- January 2024 revenue: $9,601.37 across 62 orders
- February 2024 revenue: $1,253.78 across 8 orders
- Highest-revenue customer: Jennifer Davis, with approximately $538.91 across three orders

## Data Quality
The checks performed found no missing values, duplicate rows, duplicate order numbers, shipping dates before order dates, or mismatched totals under the tested calculation rule.

## Business Recommendations
- Investigate differences in monthly order volume and confirm date coverage.
- Examine purchasing patterns among high-revenue customers.
- Investigate differences in order values across quantity groups.
- Monitor revenue, order volume and average order value over time.

## Limitations
The dataset contains only 70 orders and does not identify individual products. Findings describe this sample and should not automatically be generalised to the entire business.
